# KontextLab

德语内容安全语境研判与规则一致性分析实验室。

**在线体验：https://hallodongyue-lang.github.io/kontextlab/**

## 功能

- 40 条原创虚构德语案例与中文释义
- 六维语境框架、证据记录、不确定性与复核状态
- 本地 A/B 标注槽位，一致率、Cohen’s Kappa、交叉表与分歧分析
- 可视化研究看板、Markdown 报告、CSV 导出、JSON 备份及合并导入

## 运行与部署

当前仓库是单文件版本：下载 index.html 即可在电脑浏览器运行，无构建依赖、模型调用或付费 API。GitHub Pages 使用 main 分支根目录发布。手机建议用上述 HTTPS 地址打开。

## 方法与研究边界

所有案例、参考标签、规则编号与优先级均为项目自定义，不代表 TikTok 官方审核政策。公开来源入口见应用规则页：https://www.tiktok.com/community-guidelines/ 。

参考标签不是客观真值。讽刺不自动构成违规；持续性也并非所有严重骚扰成立的必要条件。六维框架受语用学和多层话语分析启发，并非完整 DIMEAN 实现。

默认没有标注实验结果。统计仅依据已保存标注，未配对项不进入一致性分母；随机一致概率为 1 时 Kappa 无定义。A/B 不代表实际参与人数，同一人使用两轮时须披露，查看参考标签会影响独立性。预编码场景和规则提示也可能影响标注。

小规模人工样本不可推断真实平台分布。规则引擎依赖预编码语境元数据提供分组和优先级，不对自由文本自动判违规。

## 数据保存

所有标注保存在当前浏览器，无后端同步。换设备、网址或清理浏览器前请导出 JSON。两人可分别使用 A、B 槽位，之后合并备份；同一槽位冲突时拒绝导入，避免静默覆盖。CSV 仅供分析，不是可导入备份。

## 验证

已检查 40 个案例唯一性、四个视图渲染、Kappa 空样本与退化边界、完全一致和完全分歧、报告、导入校验、输出转义与 CSV 公式防护；浏览器验证了保存、删除及初始无数据状态。尚未进行真实手机测试或多人标注实验。
